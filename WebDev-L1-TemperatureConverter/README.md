# Temperature Converter Website

Oasis Infobyte SIP — **Web Development & Designing (Level 1 - Task 3)**[cite: 2, 6, 46].

## Features
- Converts temperatures between Celsius (°C), Fahrenheit (°F), and Kelvin (K)
- Input validation for empty or non-numeric values
- Absolute zero validation (`-273.15 °C` / `0 K`)
- Clean centered UI displaying all converted units clearly

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
